# Секреты и сообщения об ошибках

Не публикуйте `.env`, токены, api_hash, файлы сессий и сертификатов.
Файлы с такими данными исключены через .gitignore, но перед git add проверяйте изменения.
В репозитории есть проверка типичных случайных утечек; она не заменяет внимательный просмотр.

При сообщении об ошибке приложите шаги воспроизведения и очищенные журналы.
Не прикладывайте реальные персональные данные пользователей формы.
Если нашли уязвимость, не размещайте рабочие секреты или данные чужой установки
в публичном Issue. Сначала опишите проблему без чувствительных значений.

Публичный API намеренно поддерживает разные сайты. Для своей установки настройте
ограничения хостинга и не используйте результат поиска как доказательство личности.
